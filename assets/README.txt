CYBERTWIN PAGE PHOTOS — SAVE YOUR IMAGES HERE
================================================
Save your pictures in THIS folder (CyberTwin/assets/) with EXACTLY these
file names (png, jpg, jpeg or webp — any size, ~1 MB or less is best).
The app embeds them automatically, no code changes needed. Restart with:
    streamlit run app.py
Pages without a matching file show the built-in illustration instead,
so nothing ever appears broken or blank.
